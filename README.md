# 🥦 Whack-a-Broccoli

A browser game built by **kids + an AI** — together.

## What this is

A 2-player whack-a-broccoli game where you smash flying broccoli with a giant
cartoon hand. Whack candy by mistake? Bomb explodes, lose a point. The whacked
broccoli bits fall to the bottom of the screen and pile up.

But the game is only half the point. The **other** half is the kids learning
how a coding AI (a Large Language Model, or LLM) works. At every step, the
kids say *what they want in plain English* — and the AI turns it into real,
working code. They watch the game grow one prompt at a time.

## How to play

1. Open `index.html` in any browser (double-click the file, or run
   `open index.html` from the project folder).
2. *(2-player mode lands in v7)*
   - **Left player:** keys **A / S / D / F**
   - **Right player:** keys **J / K / L / ;**
3. Smash broccoli 🥦 = **+1 point**
4. Smash candy 🍬 = **−1 point** (and a bomb goes off)
5. Highest score after 30 seconds wins.
